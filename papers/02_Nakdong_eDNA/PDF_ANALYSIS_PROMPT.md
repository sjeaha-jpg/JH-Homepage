# PDF 분석 요청문

아래 PDF를 처음부터 끝까지 읽고, 문서에 실제로 근거가 있는 내용만 한국어로 정리해줘.

대상 파일: `ssrn-7434558.pdf`

## 작업 원칙

- 먼저 PDF의 제목, 저자, 발행일, 문서 유형을 확인해.
- 본문을 충분히 읽은 뒤 답변을 작성해. 초록만 보고 추론하지 마.
- 중요한 사실, 수치, 주장에는 가능한 경우 페이지 번호를 `[p. 3]` 형식으로 표시해.
- 문서에 없는 내용은 추측하지 말고 `문서에서 확인되지 않음`이라고 표시해.
- 저자의 주장과 네가 해석한 내용을 구분해.
- 통계적 유의성, 인과관계, 표본의 대표성처럼 해석에 주의가 필요한 부분은 과장하지 마.
- 표와 그림은 본문과 대조해 핵심 의미를 설명해.

## 출력 형식

### 1. 한눈에 보는 요약

- 이 문서가 다루는 문제:
- 핵심 결론 한 문장:
- 가장 중요한 근거 3가지:
- 실무적 또는 학술적 의미:

### 2. 서지 정보

제목, 저자, 소속, 발행일, 문서 유형, 연구 분야를 정리해.

### 3. 연구 질문과 배경

저자가 해결하려는 문제, 기존 논의의 빈틈, 연구 질문 또는 가설을 설명해.

### 4. 방법론

연구 설계, 데이터 출처, 표본과 표본 수, 주요 변수, 분석 방법, 비교 기준을 구체적으로 정리해. 해당 사항이 없으면 없다고 밝혀.

### 5. 핵심 결과

결과를 중요도 순서로 정리하고, 수치·효과 크기·신뢰구간·유의확률 등 문서에 제시된 근거를 함께 적어. 관련 페이지도 표시해.

### 6. 저자의 해석과 주장

저자가 결과에서 어떤 결론을 도출하는지 요약해. 결과 자체와 저자의 해석을 분리해 작성해.

### 7. 한계와 반론 가능성

저자가 인정한 한계와 문서 내용을 바탕으로 추가로 주의할 점을 구분해. 특히 선택 편향, 측정 오류, 누락 변수, 인과관계의 한계를 확인해.

### 8. 용어 설명

비전공자가 이해하기 어려운 개념과 약어를 짧게 설명해.

### 9. 최종 평가

다음 형식으로 마무리해:

> 이 문서는 `[대상]`에 대해 `[방법]`을 사용해 `[핵심 결과]`를 제시한다. 다만 `[핵심 한계]` 때문에 `[해석 시 주의할 점]`이 필요하다.

마지막으로 아래 세 가지를 각각 한 줄로 답해:

- 이 문서를 한 문장으로 요약하면?
- 누구에게 유용한가?
- 읽은 뒤 확인이 필요한 열린 질문은?

분석을 시작하기 전에 PDF를 실제로 읽을 수 있는지 확인하고, 읽을 수 없다면 그 이유와 필요한 조치부터 알려줘. 분석 결과는 별도의 마크다운 파일 `PDF_ANALYSIS_RESULT.md`로 저장해.
